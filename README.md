# MRIYA TV releases

Public Android TV distribution only.

Download **MRIYA.apk** from the latest stable GitHub Release. Verify its SHA-256 against SHA256SUMS before first installation. Allow installation from the downloader/installer when Android requests it and confirm installation.

For future updates, open MRIYA → Settings → About MRIYA → Check for updates. Downloads and installations require user action. Android may request permission to install from MRIYA; return to MRIYA and select Install again after granting permission. Update the existing application without uninstalling to retain local settings and history.

Stable is the supported channel. Beta is not currently available. Only install APKs signed by the same trusted MRIYA release identity. Never bypass a package or signing mismatch warning.

Release assets:
- MRIYA.apk — signed TV application
- update-stable.json — version, source revision, size and SHA-256
- SHA256SUMS — APK checksum

This repository contains no private application source, signing keys, service credentials or server configuration.
